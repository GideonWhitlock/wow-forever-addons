## Short description

A private, explainable 24-question class and specialisation recommendation for WoW: Forever.

## Description

**Choose a Main: Forever** helps you choose the character you are most likely to enjoy—not whichever class happens to lead a damage chart.

Answer 24 questions about combat rhythm, group role, mobility, control, companions, class fantasy, playing time and long-term goals. Add optional class history and genuine exclusions. The add-on evaluates all nine Forever classes and all 27 talent paths locally, then gives you:

- a Best Gameplay Match
- a separately calculated Best Long-Term Main
- three leading recommendations from different classes
- notable alternatives within the leading class
- personalised strengths and likely frustrations
- an honest confidence label and an explanation when the decision is close

Explicit restrictions are respected before scoring. If your restrictions remove every option, the add-on asks you to revise them instead of silently ignoring them.

There is no telemetry, external AI, advertising or network service. Scores are transparent model scores, not scientifically established probabilities.

Open with `/chooseamain` (`/classcompass` remains available as a legacy alias).
