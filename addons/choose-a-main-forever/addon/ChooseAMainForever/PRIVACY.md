# Privacy

Choose a Main: Forever is entirely local.

It stores assessment answers, structured preferences, optional notes, UI settings, model versions and the previous recommendation in `ChooseAMainForeverDB`. It contains no telemetry, analytics, advertising, network client, external API call or AI service. It does not read chat, guild, friends, account identifiers, character names, realm names or location.

Resetting from the UI clears assessment data and notes after confirmation while preserving window and minimap placement.
