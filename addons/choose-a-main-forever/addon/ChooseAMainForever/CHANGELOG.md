- Anchored the Personal Notes field above the footer so it no longer stretches across or obscures the navigation buttons at any supported window scale.

## 1.0.0 — 11 October 2026

- Added the complete 24-question assessment.

- Added an in-game results model dressed in the recommended class's original Naxxramas armour set, with the specialisation result shown alongside it.
- Refit the class preview whenever the window scale or model area changes so the full head and armour remain visible.
- Added versioned profiles for all nine Forever classes and 27 named talent paths.
- Added verified Forever faction/race/class filtering, including both Skyborne alignments.
- Added deterministic gameplay and long-term scoring modes, capped preference interactions, honest confidence labels and different-class headline alternatives.
- Added contribution-driven explanations, potential frustrations and close-trade-off guidance.
- Added movable/scalable parchment UI, minimap button, saved progress, migrations, result recall and confirmed reset.
- Added automated pure-Lua tests, research record, privacy statement, maintenance workflow and release gate.
- Added original project icon artwork.
- Added mandatory persisted-state cleanup and CurseForge public-thumbnail verification gates.
