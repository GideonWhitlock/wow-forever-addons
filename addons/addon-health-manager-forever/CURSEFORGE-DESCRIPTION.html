Friendly add-on diagnostics for WoW: Forever

Addon Health Manager: Forever turns the evidence WoW exposes into a calm, readable health check for ordinary players.

It identifies definite load and dependency problems first, explains version and status warnings in plain language, provides careful performance context, and creates a privacy-clean report for CurseForge, GitHub or Discord.

What it checks

  • Installed, enabled, disabled, loaded, unavailable and load-on-demand status.
  • Missing or disabled required dependencies.
  • Forever interface-version differences and client-reported load errors.
  • Blizzard's recent, session-average and peak add-on execution-time measurements.
  • Memory as context—not as a claim that memory use equals lag.
  • Changes since the add-on's previous local scan.
  • Repeated current-session errors when Blizzard's error store safely exposes a matching path.
  • Possible shared UI ownership, labelled as a lead rather than a proven conflict.

Safe and reversible

Stage one enable or disable change for the next reload, undo it before reload, and repeat the same symptom. The add-on never edits another add-on's settings or reloads automatically.

Privacy-clean reports

Reports omit character, realm, account, guild, chat, coordinates, local variables, stack contents and SavedVariables. There is no telemetry, advertising, network service or paid feature.

Honest limits

WoW cannot reliably prove that two add-ons conflict or identify the original cause of every propagated Lua error. Addon Health Manager says when evidence is incomplete instead of inventing a diagnosis.
