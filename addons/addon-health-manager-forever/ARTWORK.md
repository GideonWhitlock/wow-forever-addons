# Artwork

`Media/AddonHealthManagerIcon.tga` is the runtime icon for **Addon Health Manager: Forever**.

The emblem combines an antique-gold shield, an emerald diagnostic pulse, and a small inspection lens. It was designed to remain recognisable at minimap size and to distinguish this add-on from Gideon Whitlock's other Forever add-ons without relying on text or a generic gear.

The bitmap was generated and refined with OpenAI's built-in image generation tool on 2026-10-11, then encoded as an uncompressed, top-left-origin, 32-bit BGRA TGA at a power-of-two 128×128 resolution. The transparent corners and circular inset were verified by decoding the final TGA back to pixels. TGA is used because the PNG build rendered as a black disc in the tested Forever client. Prompt direction specified a polished fantasy-game UI icon, circular-safe composition, gold/forest-green palette, strong small-size contrast, and no text, gear, character, scenery, or watermark.
