# Changelog

## 1.0.0 — 3 October 2026

- Initial release.
- Added hover explanations for WoW: Forever Shaman earth, fire, water, and air totems.
- Included Mana Tide Totem and excluded the removed Fire Nova and Tranquil Air totems.
- Added buff, debuff, damage, cleanse, and utility labels.
- Added support for friendly, hostile, and personal totem mouseovers.
- Added localized-name discovery and rank-independent descriptions.
- Added safe handling for Forever's restricted tooltip values.
- Added `/ttf` enable and disable commands.
