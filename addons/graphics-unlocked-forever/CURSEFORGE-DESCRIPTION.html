Graphics Unlocked: Forever

Unlock useful graphics controls that WoW: Forever supports but does not show in its standard graphics panel. Adjust each setting independently or choose a complete hardware profile from Potato to UFO.

From Potato to UFO

  • Potato, Low, Medium, High and UFO whole-system profiles.
  • Per-setting P/L/M/H/UFO shortcuts for every applicable control.
  • Ground-detail density, distance and fade up to the enhanced 256 / 500 / 370 combination.
  • Distant object, decoration, building and terrain detail plus horizon-fog distance.
  • Sharpening, render scale, dynamic-resolution minimum and reflection detail.
  • Advanced ambient occlusion, conservative shadow cascades, weather density, HDR and camera distance.
  • Current values are read from the game, and unsupported controls are clearly marked unavailable.
  • No required companion add-ons or libraries.

The complete profiles deliberately leave HDR and camera distance untouched because those are display-specific and personal choices.

Getting started

Install Graphics Unlocked: Forever, then type /guf or left-click its Elwynn-inspired minimap icon. Drag the icon to reposition it around the minimap.

Use a profile for an immediate starting point, or tune the 22 controls individually. The add-on is also available through the AddOn Compartment and Options → AddOns.

Safe restoration

Before the add-on changes a setting for the first time, it captures that setting's existing value. Use Restore on one row or Restore my original values to put everything back.

Reapply chosen values on login and zone changes is optional and starts disabled. Enable it only when you want the add-on to keep your selected values after WoW or its standard graphics options replace them.

Scope and compatibility

Built and tested for WoW: Forever 1.60.1, interface 16001. Higher detail can reduce performance. HDR requires a compatible display and operating-system configuration. Some low-level values can be replaced when you change the related standard WoW graphics option.
