Graphics Unlocked: Forever

A WoW: Forever add-on that presents carefully verified graphics console variables as clear sliders and toggles.

Current controls

- Ground detail density: 16-256
- Ground detail draw distance: 40-500
- Ground detail fade distance: 40-500
- Enhanced ground detail preset: 256 / 500 / 370
- Return to normal preset supplied by the owner: 48 / 320 / 70
- Restore my original values: returns each setting to the value captured before the add-on first changed it

Additional advanced controls

- Distant object, decoration, building and terrain detail
- Horizon fog start
- Contrast-adaptive sharpening and minimum dynamic render scale
- Ambient-occlusion method, horizon threshold, detail strength and blur passes
- Native HDR output and HDR intensity
- Shadow cascade count, restricted to the conservative 1-4 range
- Maximum camera zoom
- Weather-effect density
- Render scale and reflection detail mode
- Five one-click hardware profiles: Potato, Low, Medium, High and UFO
- Optional reapply on login/zone change; disabled until the player turns it on
- Native AddOn Compartment and WoW Options entry points in addition to the standard minimap button
- Per-setting P/L/M/H/UFO quick buttons alongside every applicable individual slider or toggle

Several controls can be overwritten when the matching normal WoW graphics option changes. HDR requires suitable hardware and operating-system configuration. Advanced ambient-occlusion controls can make the image look worse as well as better.

Commands

/guf - open or close the options window
/guf list - list available controls and their console-variable names
/guf preset enhanced - apply the enhanced ground-detail values
/guf preset normal - apply the supplied normal ground-detail values
/guf preset potato|low|medium|high|ufo - apply a hardware profile
/guf preset max - alias for UFO
/guf set <id> <value> - change a control
/guf reset <id> - restore the value captured before this add-on first changed it
/guf reset all - restore every captured value
/guf minimap - hide or show the minimap button
/guf status - show the add-on and interface versions

The minimap button matches the other WoW: Forever add-ons: click to open settings and drag to reposition it around the minimap.

Higher density and distance can reduce performance. Changing WoW's own Ground Clutter setting may overwrite these values; reopen this add-on to review the current values.
