Objective Hider for RestedXP: Forever 1.0.0

Independent compatibility utility. Not affiliated with, endorsed by, or supported by RestedXP.

Left-click the circular minimap button or use /rxpoh to toggle Blizzard's objective tracker.
Right-click the minimap button or use /rxpoh settings to open the native settings page.
Drag the button to move it around the minimap rim.
Forever's keybinding interface is not used. Use the minimap button or slash command.
This build creates no keyboard-enabled frame and installs no binding or binding override.
At startup it defensively releases only the exact legacy binding-owner/settings frames from the withdrawn 0.1.1 test build, if they still exist.

Commands:
  /rxpoh on | off | toggle
  /rxpoh mode rxp | mode always
  /rxpoh status | settings | reset | recover

The add-on never modifies RestedXP, its guides, artwork or SavedVariables. It changes only the
visibility of Blizzard's ObjectiveTrackerFrame and defers that work during combat.
