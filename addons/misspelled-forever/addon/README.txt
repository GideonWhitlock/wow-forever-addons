MISSPELLED: FOREVER

Misspelled: Forever checks the words you type into World of Warcraft chat.
Completed words that are not in the selected dictionary are coloured light blue.
Right-click a highlighted word to replace it with a suggestion, ignore it for the
current session, or add it permanently to your personal dictionary.

FEATURES

- Checks completed words while you type without sending anything automatically.
- Removes its colour markers before a message is sent.
- Right-click correction suggestions.
- Personal dictionary with add and remove controls.
- Automatic dictionary choice from the game locale.
- English (UK), English (US), French, German, Italian, Russian and Spanish.
- Friend and guild-member names are accepted automatically when available.
- WIM compatibility inherited from the established Misspelled engine.
- Minimap button using the project artwork, with a saved draggable position.

COMMANDS

/mf                     Open settings.
/mf dictionary          Edit your personal dictionary.
/mf help                Show command help.
/mf minimap             Show or hide the minimap button.
/mf reset               Reset the minimap button position.
/misspelledforever      Open settings.

MINIMAP BUTTON

- Left-click opens Misspelled: Forever settings.
- Right-click opens the personal dictionary.
- Drag the button to move it around the minimap.
- Show or hide it from settings or with /mf minimap.

INSTALLATION

Extract the MisspelledForever folder into the WoW: Forever Interface\AddOns
folder. Restart the game or reload the user interface, then enable
"Misspelled: Forever" in the AddOns list.

NOTES

The word currently being typed is checked after a word-ending space or punctuation
mark is entered. Dictionary changes require a UI reload because the selected
dictionary is loaded when the add-on starts.
