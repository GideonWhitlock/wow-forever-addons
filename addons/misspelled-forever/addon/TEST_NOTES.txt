MISSPELLED: FOREVER - LIVE TEST CHECKLIST

Version 1.1.8 keeps the Enter pre-hook removed and no longer calls Blizzard's
protected chat-activation function from its secure post-hook. Enter `/target` followed by
the exact name of a nearby enemy and confirm the target changes without a blocked-action
dialog. This was owner-tested successfully on 11 November 2026.

For the keyboard-focus report, open chat during combat, type a draft, and click into
the world. Press the normal Open Chat key, type again, and press Escape. If keyboard
focus fails to return, compare the same steps with Misspelled disabled.

1. Enable the add-on, log in, and confirm there are no Lua errors. Confirm the
   parchment-and-quill minimap button is visible and centred on the minimap border,
   not inside the circular map area.
2. Left-click the minimap button and confirm settings open. Right-click it and
   confirm the personal dictionary opens. Drag it around the minimap, reload, and
   confirm its angle is retained on the border. Test the visibility checkbox and
   /mf reset. If UI scale or minimap size changes, confirm the button remains on the ring.
3. Open chat and type: "This is a sentnce ". Confirm `sentnce` itself appears
   light blue after the trailing space is entered.
4. Backspace over the trailing space and part of the misspelling, then retype the
   correct word. The old highlight should disappear immediately. Separately,
   right-click a highlighted misspelling and confirm only the chosen word changes.
5. Send the corrected message. Confirm the recipient sees plain text without colour
   codes and the game remains connected.
6. Type a genuine custom name followed by a space. Right-click it and choose
   Add to Dictionary. Retype it and confirm it is no longer highlighted.
7. Enter /mf dictionary, remove that test word, reload, and confirm it is flagged.
8. Enter /mf, switch between enGB and enUS, reload, and confirm the selected
   dictionary is retained.
9. Paste a message containing an item link and ordinary words. Correct a misspelling
   without damaging the item link, then send it.
10. Test party, guild and whisper chat edit boxes and confirm checking works in each.
11. If WIM is installed, repeat correction and sending from a WIM message box.

Live game interaction is intentionally still required for the checks above.
