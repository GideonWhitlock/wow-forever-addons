MISSPELLED: FOREVER - LIVE TEST CHECKLIST

Version 1.1.18 masks channel-coloured edit-box shadows with a neutral black
overlay shadow. With Prat using a black background and a coloured edit box,
choose a contrasting Misspelled colour and type several repeated misspellings.
Every completed misspelling should use only the chosen colour, with no cyan
halo from Prat's channel shadow. Repeated identical misspellings must remain
evenly aligned from the first word to the last.

Version 1.1.17 restores mouse-based right-click lookup. Type several words with
a highlighted misspelling away from the text cursor, then right-click that word.
Confirm suggestions, Ignore All and Add to Dictionary appear and work.

Version 1.1.16 keeps the fallback chat caret visible independently of spelling
overlays. Open an empty chat box, type one character, move through a longer
draft, click out of chat and reopen it, and paste text wider than the edit box.
Confirm the caret remains visible or restores itself at every insertion point.

Version 1.1.15 guards dictionary lookup against malformed UTF-8 word slices
created by Lua's byte-based matching of pasted smart punctuation. Paste a line
containing curly apostrophes, curly quotation marks or an em dash into chat and
confirm that the draft remains unchanged, surrounding misspellings are still
highlighted and no Invalid UTF-8 character error appears. Paste a line wider
than the chat box, press Left and Right repeatedly, and confirm the visible
caret remains present as the edit box scrolls through the draft.

Version 1.1.14 keeps the Enter pre-hook removed and no longer calls Blizzard's
protected chat-activation function from its secure post-hook. Enter `/target` followed by
the exact name of a nearby enemy and confirm the target changes without a blocked-action
dialog. This was owner-tested successfully on 11 November 2026.

For the keyboard-focus report, open chat during combat, type a draft, and click into
the world. Press the normal Open Chat key, type again, and press Escape. If keyboard
focus fails to return, compare the same steps with Misspelled disabled.

For the long-draft report, type beyond the visible width of the chat box. The
visual overlay should hide instead of moving onto another word; right-click
corrections should remain available. Shorten or clear the draft and confirm the
overlay returns. Open a chat edit box created after login and confirm it also
receives spelling and right-click support.

With Leatrix Plus's "Use arrow keys in chat" enabled, type a completed
misspelling, move the insertion caret into and through that word with Left and
Right, and confirm the caret remains visible and moves normally at every
position, including spaces and the end of the message. The overlay for only that
active word should hide while the caret is inside it and return after the caret
leaves. Confirm Misspelled never changes the edit box's AltArrowKeyMode setting.

1. Enable the add-on, log in, and confirm there are no Lua errors. Confirm the
   parchment-and-quill minimap button is visible and centred on the minimap border,
   not inside the circular map area.
2. Left-click the minimap button and confirm settings open. Right-click it and
   confirm the personal dictionary opens. Drag it around the minimap, reload, and
   confirm its angle is retained on the border. Test the visibility checkbox and
   /mf reset. If UI scale or minimap size changes, confirm the button remains on the ring.
3. Open chat and type: "This is a sentnce ". Confirm `sentnce` itself appears
   light blue after the trailing space is entered.
4. Backspace over the trailing space and part of the misspelling, then retype the
   correct word. The old highlight should disappear immediately. Separately,
   type `sentnce` without a trailing space, right-click it, choose a correction,
   and confirm only the chosen word changes.
5. Send the corrected message. Confirm the recipient sees plain text without colour
   codes and the game remains connected.
6. Type a genuine custom name followed by a space. Right-click it and choose
   Add to Dictionary. Retype it and confirm it is no longer highlighted.
7. Enter /mf dictionary, remove that test word, reload, and confirm it is flagged.
8. Enter /mf, switch between enGB and enUS, reload, and confirm the selected
   dictionary is retained.
9. Paste a message containing an item link and ordinary words. Correct a misspelling
   without damaging the item link, then send it.
10. Test party, guild and whisper chat edit boxes and confirm checking works in each.
11. Open settings, change the highlight colour to #FFCC00 and press Apply. Confirm
    the preview and any visible misspelling change immediately. Enter invalid text
    and confirm it is rejected, then use Reset highlight colour.
12. If WIM is installed, repeat correction and sending from a WIM message box.
13. With Prat enabled and its chat background set to black, choose `#FF0000`,
    type `test worins `, and confirm the misspelling is solid red without cyan
    fragments from the underlying whisper or channel text.

Live game interaction is intentionally still required for the checks above.
