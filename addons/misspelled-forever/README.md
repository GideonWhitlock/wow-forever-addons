# Misspelled: Forever

Misspelled: Forever checks spelling while you type, highlights likely mistakes and offers right-click corrections. It is based on Misspelled by Nathan Pieper and adapted for WoW: Forever.

The prepared public release is version **1.1.0** for WoW: Forever **1.60.1** (interface **16001**). Install the `MisspelledForever` folder in `_classic_beta_/Interface/AddOns/` and enable it from the character-selection AddOns list.

The add-on includes dictionaries and its required libraries. Saved custom dictionary and setting data remain in `MisspelledForeverDB`.

See the source in [addon](addon/) and released changes in [CHANGELOG.md](CHANGELOG.md).
