# Looking for Group: Forever

Looking for Group: Forever adds a single, deliberate contact button to World of
Warcraft: Forever's Looking For Group browser. Select a listing and click once to
whisper the leader with your class and chosen Group Finder role, for example:

> Warrior DPS here

## Features

- One-click whisper for the currently selected Group Finder listing.
- Uses the role or roles selected in the Group Finder: Tank, Healer and/or DPS.
- Includes the player's localized class name.
- Editable message template with `{class}`, `{role}`, `{name}` and `{level}`.
- Three-second duplicate-click protection for the same leader.
- Right-click an individual player listing and choose **Suggest invite to party
  leader**. The suggestion is posted in party chat and whispered to the leader;
  when you are the leader, the party message is sufficient.
- If chat is restricted, prepares the message in the whisper box instead of losing it.
- Draggable minimap button: left-click opens or closes Looking For Group;
  right-click opens settings.
- No automatic searches, applications, invitations or unsolicited messages.

## Commands

- `/lfgmsg` or `/lfgmsg options` — open settings.
- `/lfgmsg preview` — print the current message preview.
- `/lfgmsg send` — send to the selected listing, like the on-screen button.
- `/lfgmsg minimap show|hide` — show or hide the minimap button.
- `/lfgmsg reset` — restore defaults.
