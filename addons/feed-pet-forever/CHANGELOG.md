# Changelog

This changelog records public Release versions of Feed Pet: Forever. Dates use ISO format.

## 1.0.2 — 2026-10-02

- Corrected the displayed addon title to **Feed Pet: Forever**.
- Kept the `FeedPetForever` folder, `FeedPetForeverDB` saved settings, and `/fpf` commands unchanged.
- Feeding behavior is unchanged from 1.0.0.

## 1.0.1 — 2026-10-02

- Changed the displayed addon title to **Feed Pet; Forever**.
- Kept the `FeedPetForever` folder, saved settings, and slash commands unchanged.
- Feeding behavior is unchanged from 1.0.0.

## 1.0.0 — 2026-09-27

- Published the first public Release under the title **Feed Pet Forever**.
- Added a flashing Feed Pet reminder for unhappy or content hunter pets.
- Added secure one-click feeding using suitable food from carried bags.
- Added bag-slot revalidation when the alert is clicked.
- Added an optional no-food warning with the current pet's diet in its tooltip.
- Added suppression during combat, death, an absent or dead pet, flight paths, mounting, vehicles, active feeding, and Feed Pet cooldowns.
- Added movable, resizable, per-character alert settings.
- Added a draggable minimap button for settings and layout preview.
- Added minimap position and visibility settings and `/fpf minimap on` and `/fpf minimap off`.
- Released without external addon dependencies.
