# Changelog — Combo Points: Forever

This changelog records verified changes present in the packaged releases. Dates use ISO format.

## 1.0.6 — 2026-10-03

- Renamed the add-on to **Combo Points: Forever** in the TOC title, minimap tooltip, chat prefix, and README.
- Kept the circular red **CP** artwork for both nameplate points and the minimap button.
- Retained WoW: Forever 1.60.1 / Interface 16001 compatibility metadata.

## 1.0.5 — 2026-10-03

- Replaced the nameplate combo-point artwork with the same high-resolution circular red **CP** artwork used by the minimap button.
- No runtime logic changed from 1.0.4.

## 1.0.4 — 2026-10-02

- Added a standard 32-pixel draggable minimap button with a 20-pixel circular **CP** icon.
- Added left-click control for empty slots, right-click preview, and drag positioning.
- Added `/cpf minimap` to hide or restore the minimap button.
- Added per-character saved settings for minimap angle and visibility.
- Renamed the add-on to **Combo Points Plate: Forever**.

## 1.0.3 — 2026-10-01

- Replaced the combo-point artwork with a high-resolution gold-and-black diamond **CP** badge.
- No runtime logic changed from 1.0.0.

## 1.0.2 — 2026-10-01

- Increased the circular gold-ringed **CP** artwork to high resolution.
- No runtime logic changed from 1.0.0.

## 1.0.1 — 2026-10-01

- Replaced the initial badge artwork with a circular gold-ringed black **CP** badge.
- No runtime logic changed from 1.0.0.

## 1.0.0 — 2026-10-01

- Initial packaged release for WoW: Forever 1.60.1 / Interface 16001.
- Displayed combo points above the current hostile target's visible nameplate.
- Supported the legacy target-bound combo-point API with a player-resource fallback.
- Added adaptive maximum points, dim empty slots, and a short gain flare.
- Added `/cpf test`, `/cpf scale`, `/cpf offset`, `/cpf spacing`, `/cpf empty`, and `/cpf reset`.
