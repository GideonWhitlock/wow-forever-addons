# Release and media checklist

This checklist is intentionally gated. Do not complete a later phase merely because the files exist.

## 1. Owner acceptance and live test

- Complete every item in `addon/TESTING.md` on installed Forever build `1.60.1.70338` or newer.
- Record the exact build, character/UI scale matrix, test date and failures.
- Obtain owner acceptance for default wording, intervals, card prominence, dismissal wording and overdue one-off behaviour.
- Resolve all blocker/major defects and re-run automated validation.
- Release version set to `1.0.0` after explicit owner launch acceptance on 11 October 2026.
- Preserve a rollback copy of the accepted add-on folder and release ZIP.

## 2. Public source and CurseForge

- Commit the accepted source, docs, licence, artwork record and issue form to `GideonWhitlock/wow-forever-addons`.
- Confirm the public Source, Changelog and Report an issue links return the intended pages.
- Add the add-on to the repository site only when its public CurseForge URL exists.
- Create the CurseForge project as **Gentle Reminder: Forever** with the prepared description and search-aware summary:
  - “Warm, private break, playtime, hydration, stretch and bedtime reminders for WoW: Forever—with one-off timers, snooze choices and combat-aware delivery.”
- Use `artwork/project-logo.png` as the project logo.
- Upload only the accepted ZIP, select the **Forever** flavour and exact supported 1.60.x version, and keep the initial file release type honest.
- Add genuine in-game screenshots only: main settings, reminder card, one-off dialog, and minimap tooltip. Do not use mockups as screenshots.
- Confirm no personal reminder text, character/account identifiers or private chat is visible in captures.
- Add only the established external support link: <https://github.com/sponsors/GideonWhitlock>. Keep it outside the game and unobtrusive.
- Register the project in the same shared maintenance/version tracker used by the other Gideon add-ons after the public file is downloadable.

## 3. YouTube main demonstration

Start only after the public download works and genuine capture exists.

- Record a first-person Gideon walkthrough: why it exists, profile setup, one-off reminder, combat deferral, snooze, privacy, reset/recovery, and where to report issues.
- Demonstrate behaviour; do not stage claims that were not live-tested.
- Include captions, chapters, the CurseForge link, public source, issue route, MIT status and an AI-art disclosure for the project logo.
- Use a purpose-built 16:9 thumbnail based on genuine UI capture plus the project emblem; keep text short and readable.
- Add to the established WoW: Forever add-on playlist.

## 4. Purpose-built Short

- Capture vertically rather than cropping the long video.
- Structure: “lost track of time?” → one-off or recurring setup → gentle card after combat → “your reminder, your choice.”
- Use first-person Gideon narration and burned-in captions, with no health claims or guilt language.
- Link the full demonstration and disclose the AI-generated project emblem.

## 5. Follow-up

- At 7 and 28 days, record downloads, video retention/click-through, repeated support questions, crash/error reports and wording feedback.
- Prefer product fixes and clearer docs over adding more notification intensity.
- Never collect in-game telemetry to fill analytics gaps.
